# TP XML - Gestion des températures des villes

## Présentation
Ce projet consiste à gérer les mesures des températures de différentes villes à une date donnée en utilisant les technologies XML.

## Objectifs
1. Représentation graphique de l'arbre XML.
2. Création d'une DTD.
3. Création d'un document XML valide basé sur la DTD.
4. Création d'un schéma XML (XSD).
5. Création d'un document XML valide basé sur le XSD.
6. Transformation XML vers HTML avec XSLT.
7. Transformation XML vers SVG avec animation.

## Technologies utilisées
- XML
- DTD
- XSD
- XSLT
- HTML
- SVG
- Oxygen XML Editor

## Structure du projet
- DTD : fichiers de validation DTD.
- XSD : fichiers de validation XML Schema.
- XSLT : feuilles de transformation HTML et SVG.
